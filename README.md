# Jeven 个人主页 — Matrix + Minecraft 极客风

单页静态站点，无需构建。绿黑终端 / 像素块外观，带可选 Matrix 雨（尊重 `prefers-reduced-motion`）。

## 本地预览

在仓库根目录执行：

```bash
python3 -m http.server 8080
```

浏览器打开：http://localhost:8080

## 文件

| 文件 | 说明 |
|------|------|
| `index.html` | 结构与中文主文案 |
| `styles.css` | 像素 / CRT / 方块按钮样式 |
| `matrix.js` | 轻量 Matrix 雨（可关） |

## 字体（Google Fonts CDN）

- **Press Start 2P** — UI / 英文标题
- **VT323** — 终端提示符与 log
- **Noto Sans SC** — 中文正文

## 部署（可选）

GitHub Pages / Cloudflare Pages / Vercel：上传或连接本目录即可。联系区占位符需自行替换。
